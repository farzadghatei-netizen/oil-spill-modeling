# Oil Spill Modeling

Research repository focused on oil spill trajectory modeling, weathering processes, and data-driven approaches.

**Current focus:**  
Reproducing previous work, building reproducible wind and current data pipelines, and developing Lagrangian particle models for the Persian Gulf and Oman Sea.

## Environment Setup

mamba env create -f environment.yml
conda activate oilspill

## Structure

- notebooks/ — Analysis and experiments
- scripts/ — Reusable pipelines
- data/ — Processed datasets (raw data not tracked)
- docs/ — Notes and documentation
